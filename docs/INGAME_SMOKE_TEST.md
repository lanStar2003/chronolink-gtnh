# GTNH 2.8.4 游戏验收

目标仅为 GTNH 2.8.4。不要直接使用重要存档。构建结果以指定提交的 Actions 记录为准；下面所有游戏内项目当前均为 **NOT RUN**，不能把核心测试、语法检查、编译或重混淆等同于游戏测试。

| 项目 | 验收条件 | 状态 |
|---|---|---|
| 客户端与独立服务端启动 | 无类加载、配方注册或客户端隔离错误 | NOT RUN |
| 版本检查 | 错误 GT 版本明确拒绝加载 | NOT RUN |
| 配方与模型 | 铁、玻璃、圆石、木板可合成；6 个方向放置与纹理正常 | NOT RUN |
| 简单原生面板 | 中文、各 GUI 缩放、按钮、过滤样品操作不截断、不吞物品 | NOT RUN |
| 箱子与分面机器 | 物品、metadata、NBT 和总数量守恒，遵守分面槽位限制 | NOT RUN |
| 满箱与部分接收 | 不删除余量、不重复交付 | NOT RUN |
| 流体与气态流体 | 水、蒸汽和其他 Forge 介质不串流，不自动转化能源 | NOT RUN |
| GT EU | 32 V/1 A 等已知电压验证实际扣账；返回值按安培处理 | NOT RUN |
| 过压与未知电网 | 默认拒绝危险输出，不能以炸机器探测额定电压 | NOT RUN |
| RF | 真实设备主动、被动收发共用限额；模拟不改变余额 | NOT RUN |
| EU/RF 分账 | 不自动互相转换，不走错资源域 | NOT RUN |
| 私有权限 | 两名玩家同编号不串网，非所有者不能配置或普通拆除 | NOT RUN |
| 配置与绑定 | 带缓冲节点不能改网络、方向、资源类型；改配置后需再启用 | NOT RUN |
| GUI 异常操作 | 旧窗口、越界编号、拖拽、双击不复制过滤样品或改远处节点 | NOT RUN |
| 跨维度与区块 | 仅调度已加载节点，卸载清除旧引用，不自行强加载 | NOT RUN |
| 保存、拆除与重新放置 | 缓冲和配置保存，掉落仅一份；重放置默认暂停 | NOT RUN |
| 创造模式 | Pick block 不复制资源；含缓冲的创造拆除被拒绝 | NOT RUN |
| 异常 API / NBT | 节点隔离并保留恢复内容，不盲目重试、退款或删资源 | NOT RUN |
| 特效与性能 | 真实传输才播放，暂停后熄灭；记录实际 MSPT 与吞吐 | NOT RUN |

每项必须记录实际设备注册名、模组版本、配置、操作及预期/实际数量。通过一种标准接口不等于所有设备兼容。

本版未实现激光、数据/算力光缆、AE 网格/库存桥、独立氧气接口、特殊深层库存、LogisticsPipes 请求协议和公开共享网络。

不同区块和第三方容器的保存不具有统一原子事务；非正常退出测试只能记录已知风险，不能宣称任何崩溃都不丢失或复制资源。
