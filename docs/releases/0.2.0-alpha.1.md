# 中心 + 多路连接器：局域直连 / 存储网络

目标仅 GTNH 2.8.4。新版保持简洁原生单页 GUI，不是网页原型。

## 本版内容

- 新增时枢网络中心：命名网络，切换局域直连和存储网络；显示物品、液体、气体、EU、RF 的实际输入/输出速率、库存及资源目录。
- 新增管状多路连接器：无相邻接口时仅中心小方块；六面自动识别库存/流体/EU/RF 接口并伸出细连接臂，碰撞及选择框同步改变。
- 同一个连接器同时处理多种资源，六面各自选择输入/输出/关闭，不再切换资源类型。
- 局域模式直接从来源交付目的地。目的地满时不预先抽走资源，没有常规中心仓库或连接器缓冲。
- 存储模式：中心通过真实 AE 网格节点访问原有物品/流体存储；遵守 AE 供电、频道和安全权限。没有 AE 时可插入物品、流体/气体、RF 容量卡。
- EU 在存储模式下直接接入 GT 原生无线团队账户，读写同一份余额，不在本 mod 中另造电池账。RF 不转换成 EU。
- EU 输出默认自动读舱室、线缆与已知末端的安全电压，也可手动设置；自动判断不完整则停止自动输出。
- 原生蓝青面板、三轨道悬浮核心和实际传输动效。
- 新流程不需要绑定器；旧方块和物品 ID 保留供旧存档使用，旧绑定器不再有新配方。

## 使用

1. 放置网络中心，命名；局域模式不需要任何容量卡。
2. 来源旁放一个新连接器，接收端旁放另一个；选择同一个中心，来源面设输入、目的面设输出，再启用。
3. 做存储网络时，在中心切换模式。把 ME 线缆接到中心并保证 AE 在线，或在中心插容量卡；输出面从目录选择物品/介质，也可用光标样品指定，右键清除。
4. 中心和端点都需处于已加载区块。没有强制区块加载，不会操作离线机器。

## 更新与重要边界

退出游戏后移除旧 ChronoLink JAR，只保留本版；不要改整合包的 GT/AE 版本。先备份存档。
旧连接器排空后，空手潜行右键可转换为新管状连接器；新节点默认暂停。旧的非空节点不会强制转换或丢弃缓冲。

- 每面可以选择一种物品及一种流体/气体输出，同时保留 EU/RF。多品种固定输出可使用其他面或更多连接器。
- 局域 EU 不缓存也不变压，保留来源原生电压包；高压直接给低压设备时会拒绝。需要按目标电压分配时使用存储网络。
- 同一 GT 团队的多个中心看到的是同一个原生无线 EU 余额，不能相加当成多份电量。当前每连接器最多64A，物品/流体/RF沿用配置限流。
- AE 满、断电、无频道或无权限时，不会假装存入成功；已连接 AE 时也不会偷偷把新入库物资改存容量卡。之前留在卡里的库存仍可取出。
- 容量卡属于真正的中心库存；不能取走仍占用的容量。中心正常采掘会携带身份、卡和库存。
- 不能由 AE 原生流体类型无损表示的特殊 NBT 流体会被拒绝，而不是删掉标签。
- 异常外部接口才可能产生隔离的应急保管/未决记录；它不是正常缓存，也不会自动重放或退款。不同区块存档不是原子事务，不能保证任意崩溃绝无损失。
- 这是标准资源边界和原生 AE 存储桥，不是 AE 频道的无线延长，也未实现激光、数据光缆、独立氧气及所有专用导管协议。
