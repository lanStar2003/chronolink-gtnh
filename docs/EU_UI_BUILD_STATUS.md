## 功能变化

- EU输入和输出显示为EU/t，按原有最近20游戏tick的实际转移总数除以20，不是只更换单位文字。RF同样显示RF/t。
- 库存仍是总EU/RF，不除以20；物品、液体、气体的每游戏秒统计保持原样。
- 持续IV 1A对应8192 EU/t，IV 4A对应32768 EU/t。自动/手动电压、安培以及V×A理论上限与全网实际平均吞吐分开展示。
- 右侧立方体可以直接点击上、北、东面，下方西、南、下三个按钮让另外三面也直接可达；不再用原来的六个方向选择按钮。
- 默认左键循环关闭/输入/输出，右键反向；选择输入、输出或关闭画笔后，点击或拖动划过多个面即可批量应用同一模式。
- Shift点击或中键仅选中该面，左侧编辑其过滤、电压、安培；面颜色和入/出/关文字同时展示，悬浮提示显示方位、相邻端口和接口类型。
- 物理面和目标模式直接传给服务端；快速循环基于服务端当前状态计算。仍检查所有者、容器、距离、故障，并保留有界请求队列。
