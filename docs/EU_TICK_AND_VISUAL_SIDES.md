# EU/t 与右侧可视化六面配置

接续 work/network-v2-completion / PR #1，目标仍为 GTNH 2.8.4。此改动不修改构建配置、内部版本号或已经发布的 Release。

## 能量显示

中心总览的 EU 输入/输出改为 EU/t，RF 为 RF/t。后台的实际20tick流量总数不改变，仅在显示时除以20，因此不是只改单位文字。库存仍显示总 EU/RF，不除以20。物品、流体、气体仍按20游戏tick对应的每游戏秒统计。

持续 IV 电压8192V：1A 为8192 EU/t，4A 为32768 EU/t。实际吞吐量受供需及安培限制，不能只根据 IV 等级就认定每tick实际交付8192。界面将“实测20tick平均值”和“选中面的 V×A 输出上限”分开。

常用电压数字不缩成有歧义的8.2k；小流量平均值保留0.05 EU/t等小数。极大无线余额在表格紧凑显示，悬浮提示提供完整数值。

## 右侧六面配置

连接器不再排列六个方向按钮让玩家先选方向再循环模式。右侧为直接可点击的立方体：上、北、东三个可见面，以及下方西、南、下三个背面/底面按钮，六面都能直接设置。方位固定使用世界方位，不随玩家站位变化。

- 默认循环：左键在关闭、输入、输出间切换；右键反向切换。
- 右下角选择输入/输出/关闭画笔后，左键或按住左键划过多个面，一次性给它们应用同一设置。
- Shift点击或中键只选中该面，不更改输入输出；左侧编辑所选面的多资源过滤、电压和安培。
- 蓝青表示输入，橙色表示输出，灰色表示关闭；同时显示入/出/关文字，不只依赖颜色。
- 悬浮提示显示绝对方位、相邻端口、识别到的资源接口；小绿点表示检测到相邻连接。

所有写入仍由服务端验证玩家、当前容器、距离和故障状态。画笔命令直接携带物理面与目标模式；循环也在服务端基于实际状态计算，避免连续点击使用旧快照时丢失一次切换。允许每容器每tick最多8次合法操作，队列仍有整体上限。

交互参考 Team CoFH 的 Reconfigurable Sides 说明（左键循环、右键反向）：https://oldcofh.github.io/docs/thermal-expansion/augments/reconfigurable-sides/ 。立方体绘制、文字、布局及代码独立实现，未复制其贴图或资源。

## 验证

新增226次纯生产策略断言覆盖：IV 1A/4A、储量与速率分离、小数及溢出、六个面的命中与合法指令、仅修改目标面、快速连续循环和画笔节流。本地通过；完整Forge编译结果以本次Actions为准。

实际GTNH窗口中的绘制、鼠标交互、机器传输与存档回归尚待游戏测试。此前的构建配置写入拦截没有在此改动中处理，因此本分支不是新的版本化Release；不要将内部仍为0.2.0-alpha.1的分支测试包误认成旧Release的同一文件。
