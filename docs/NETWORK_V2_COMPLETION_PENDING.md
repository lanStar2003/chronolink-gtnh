# 0.2 网络补齐：测试分支，尚未发布

本分支针对 0.2.0-alpha.1 的功能核对后补充，不应把同名测试产物误认成已发布版本。

## 改动

- 每面输出最多9种物品与9种介质；液体和气体可同时勾选，EU/RF 不受物资过滤影响。
- 目录搜索名称/注册ID、分页、多选；实时数量更新不使未变化的条目点击失效。页面/资源身份变化仍拒绝旧点击。
- 刚刚输入/输出的零库存资源仍显示实际流量；局域目录标为源可提取，不能当作中间仓储。
- 卡槽有占用条和精确容量提示；目录错误不应隔离正在正常运行的网络。
- 同一连接器可在不同面之间直接转移，源/目的同一库存仍拒绝；没有新增常规缓冲。
- EU 探测只沿已连接的原生线缆边继续；去重异常重复库存槽，避免模拟数量重复计算。
- 保留旧单项过滤 NBT 迁移，增加生产代码的原生数据与容器回归测试。

## 发布状态

本轮 `build.gradle` 的修改被平台安全检查拦截，未绕过该拦截。构建脚本与版本号暂时保留主分支现状，仅在独立分支编译/测试；不得覆盖已有同版本 Release。预期下一次新版本为 0.2.0-alpha.2，但本分支此时没有发布它。

完整 GTNH 客户端/服务端启动、AE 实网与 GT 线网、实际重启和存档回归仍待游戏验证。激光、数据光缆、AE 频道无线延长和独立氧气等不属于本轮实现。
