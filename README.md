# ChronoLink · 时枢网络

仅针对 GTNH 2.8.4 / Minecraft 1.7.10 的无线资源网络模组。

- 简单原生单页配置，不使用网页控制台。
- 物品、Forge 流体（含相应气态流体）、GregTech EU、RF 分别传输。
- 私有玩家频道，仅连接已加载端点。
- EU / RF 独立记账，不自动互相转换。

## 当前状态

正在导入第一版源码和 GitHub Actions 构建配置。完整编译、重混淆与游戏内验证结果以实际工作流及验收记录为准，不以核心测试替代游戏验证。

本仓库由所有者创建；上传时仓库可见性为 public。未包含游戏实例、存档、账号凭据或第三方整合包 JAR。
