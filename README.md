# 时枢网络 · ChronoLink

GTNH **2.8.4** / Minecraft **1.7.10** 私用无线资源网络模组。仅支持锁定整合包版本，不要求升级 GT 或 AE。

## 0.2：一个中心，一种多路连接器

**[Release 下载](https://github.com/lanStar2003/chronolink-gtnh/releases)** · **[操作说明](docs/NETWORK_V2.md)** · **[本版更新](docs/releases/0.2.0-alpha.1.md)**

连接器不再是完整方块：单独放置时是一颗小核心，六面检测相邻设备并伸出连接臂。同一颗连接器同时传物品、流体/气体、原生 EU 和 RF；不再切换资源类型，不需要绑定器。

中心提供命名网络、输入/库存/输出总览与资源目录，界面为原生单页。网络不再通过数字频道区分资源。

| 模式 | 行为 |
|---|---|
| 局域直连 | 来源直接交给接收端，正常路径没有中间库存；目标满则不抽取。需要中心，但不需要容量卡。 |
| 存储网络 | 物品/流体进入真实 AE 存储或中心容量卡；EU 使用 GT 原生团队无线账户；RF 独立容量卡。 |

中心可直接接 ME 线缆；需要正常的 AE 电力、频道和授权。AE 满或离线时拒收，不伪造余额。相同 GT 团队的多个中心共享原生 EU 余额，不是每个中心一份电量。

## 快速使用

先放中心并命名。来源和目标旁分别放新连接器，确认相同网络；选择接入面，分别设为输入、输出，再启用。附近32格内中心可自动选中，也可在面板选择自己其他已加载的中心。一个连接器最多六个独立方向。

需要仓储时，在中心切换为存储网络，并连接 AE 或插容量卡。输出物品/介质从目录选择，或用光标持有的样品复制条件；右键清除。不消耗过滤样品。

EU 默认读取接入舱室/线缆与已知末端的额定值；存在未确认线路则停止自动输出，也可手动配置。局域模式保留原始电压包，不缓存也不变压；存储模式从无线账户按目标电压输出。

## 验证与边界

GitHub Actions 要求真实依赖编译、原始加载依赖回归、几何/无缓存转运事务测试、原生 Minecraft/Forge 数据及容器适配测试、GT/AE 接口检查、重混淆和 JAR 检查通过。主分支新版本成功后自动发布带校验文件的测试版 Release，不覆盖既有版本。

实际结果以对应 Release 的 BUILD_EVIDENCE.json、DEPENDENCY_CHECK.txt 和 Actions 日志为准。**库级原生容器测试不是完整 GTNH 启动、AE 实网、GT 电网、世界保存或性能测试。** 新功能的游戏验收见 [检查清单](docs/INGAME_SMOKE_TEST_V2.md)。

仅操作已加载中心与端点，默认无强制区块加载。标准协议不等于任意模组的专用导管全部兼容。激光、数据光缆、无线 AE 频道延长、独立氧气和特殊深层库存等不包含在本次版本中。

异常外部接口导致的未决记录/应急保管不是正常缓存。不会自动重放、退款或清空坏数据；跨区块存档不是原子事务，不能承诺任何崩溃绝无资源损失。

## 开发

JDK21 构建、Java8 toolchain、Gradle8.8 / RFG1.4.6；固定 GT5 5.09.51.482、AE2 rv3-beta-695-GTNH、GTNHLib0.7.10。

```sh
gradle --no-daemon clean check reobfJar stageCloudArtifact
```

构建不读取玩家游戏目录、存档或账号；测试不自动接受 EULA，不启动完整整合包或付费云开发机。项目不打包 Minecraft 或第三方依赖类。
